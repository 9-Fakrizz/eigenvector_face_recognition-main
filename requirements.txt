# Core dependencies for vector_face_recognition/main.py

# NOTE on dlib / face_recognition on Windows:
#   `pip install face_recognition` needs to build `dlib` from source unless
#   a prebuilt wheel exists for your exact Python version. That build needs
#   CMake + a matching Visual C++ toolchain and can fail or take a long time.
#   If `pip install -r requirements.txt` fails on dlib on Windows, install
#   dlib and face_recognition via conda-forge instead (see README.md), then
#   `pip install -r requirements.txt` again to pick up the rest.
#
# On Linux / Jetson (aarch64), `pip install dlib face_recognition` normally
# builds fine directly (make sure cmake and a C++ compiler are installed:
# `sudo apt install build-essential cmake`).
